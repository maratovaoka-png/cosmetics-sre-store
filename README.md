# Online Cosmetics Store SRE Project

This project demonstrates Site Reliability Engineering practices for an online cosmetics store using microservices architecture.

## Technologies

- Docker
- Docker Compose
- Docker Swarm
- Kubernetes
- Terraform
- Ansible
- Prometheus
- Grafana
- Flask
- PostgreSQL

## Microservices

1. auth-service
2. product-service
3. order-service
4. payment-service
5. notification-service
6. review-service
